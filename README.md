# 最小二乗フィッティング・デモ

外部依存のない静的な HTML / CSS / JavaScript のデモです。`index.html` をブラウザで開くか、GitHub Pages の公開元をこのフォルダー（またはリポジトリのルート）に指定して公開できます。

キャンバスをクリックすると観測点が追加され、最小二乗法による線形回帰 `ŷ = mx + b`、決定係数 R²、平均応答に対する 95% 信頼帯を表示します。信頼帯には Student の t 分布の両側 95% 臨界値を用いています。

GitHub Pages は、GitHub のリポジトリ画面で **Settings → Pages → Deploy from a branch** を選び、公開するブランチとフォルダーを指定してください。
